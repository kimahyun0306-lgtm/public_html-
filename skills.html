03 / CAPABILITIES

SKILLS

데이터사이언스학부 전공 수업과 개인 실습을 통해 실제로 익히고 활용하고 있는 기술 역량입니다.
인위적인 수치나 과장 없이, 실제 수행 가능한 작업 범위를 중심으로 서술합니다.

01. 프로그래밍 및 데이터 처리

데이터 수집, 정제, 전처리 및 알고리즘 구현을 위한 핵심 언어와 라이브러리입니다.

Python 전공 핵심

기본 문법과 자료구조를 이해하고 있으며, Pandas, NumPy를 활용한 데이터 결측치 처리, 그룹화 연산, 피벗 테이블 생성 등 탐색적 데이터 분석(EDA) 실습에 능숙합니다.

R 통계 실습

통계학 수업에서 데이터 분석 실습용으로 학습하였으며, 데이터프레임 조작 및 기본 통계 검정(t-test, ANOVA), 회귀분석 모델 적합 및 결과 해석을 수행할 수 있습니다.

SQL 기초 활용

관계형 데이터베이스(RDB)의 기본 구조를 이해하고, SELECT, WHERE, JOIN, GROUP BY 등 표준 쿼리문을 작성하여 필요한 데이터를 추출하고 요약할 수 있습니다.

02. 통계학 및 분석 방법론

수치 이면의 패턴과 인과관계를 올바르게 파악하기 위한 이론적 기초입니다.

기초 통계학 (Statistics) 이론 및 적용

기술통계량(평균, 분산, 왜도, 첨도) 및 확률분포에 대한 이해를 바탕으로, 가설검정 및 신뢰구간 추정 등 추론 통계의 기본 원리를 적용할 수 있습니다.

탐색적 데이터 분석 (EDA) 실무 실습

데이터셋을 처음 마주했을 때 데이터 분포를 확인하고, 이상치 감지, 변수 간 상관관계 도출 등 모델링 이전의 다각도 탐색 과정을 충실히 수행합니다.

선형대수학 기초 수학적 기초

행렬 연산, 벡터 공간, 고유값 및 고유벡터 등 데이터 차원 축소와 향후 머신러닝 알고리즘 학습을 위한 수학적 기초 개념을 수강하였습니다.

03. 시각화 및 협업 도구

분석 결과를 명확하게 전달하고 프로젝트를 체계적으로 관리하기 위한 도구입니다.

Matplotlib & Seaborn 시각화

히스토그램, 산점도, 박스 플롯, 히트맵 등 분석 목적에 적합한 차트를 생성하고, 레이아웃과 색상을 정돈하여 가독성 높은 보고서용 그래프를 작성합니다.

Microsoft Excel 스프레드시트

VLOOKUP, INDEX/MATCH, 통계 함수 및 피벗 테이블을 활용하여 원시 데이터를 신속하게 집계하고 검증할 수 있습니다.

Git & GitHub 버전 관리

코드 버전 관리와 커밋 기록 작성, 브랜치 작업 및 GitHub Pages를 통한 정적 웹사이트 배포 과정을 이해하고 실천합니다.
